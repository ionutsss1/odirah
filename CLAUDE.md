# ODIRAH: design rules

- No eyebrows: never put a small label, kicker or category line above a heading. Let the heading stand alone. If context is needed, put it in the heading or the text after it.
- Keep display headlines tight: regular serif in sentence case, line-height about 1, no added letter-spacing. Keep small-caps tracking for navigation, buttons and short labels that sit beside or below content.
- Never retype the wordmark. Use `site/assets/brand/odirah-wordmark.svg`, which is extracted from the brand manual's artwork.
